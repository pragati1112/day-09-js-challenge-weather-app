# 🚀 Day 09 — Weather App

Part of my 21 Days JavaScript Challenge.

## 📌 Overview
Weather app using API to fetch real-time weather data.

## 🎯 Goal
Learn API integration and data fetching.

## 🧩 Features
- City search  
- Temperature display  
- Weather condition  
- Error handling  

## 🧠 Flow
1. Get city input  
2. Call API  
3. Fetch data  
4. Display weather  

## 🖥 Tech
HTML | CSS | JavaScript | API  

## 💡 Learning
API handling + async JS + fetch
